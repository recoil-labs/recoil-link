# Hyperlane Utils

A collection of various utilities and types for building applications with Hyperlane.
Typically not used directly but through the [Hyperlane SDK](https://www.npmjs.com/package/@recoillink/sdk) instead.

## Install

```bash
# Install with NPM
npm install @recoillink/utils

# Or with pnpm
pnpm add @recoillink/utils
```

Note, this package uses [ESM Modules](https://gist.github.com/sindresorhus/a39789f98801d908bbc7ff3ecc99d99c#pure-esm-package)
