# @recoillink/deploy-sdk

Deployment modules for [Recoil Link](https://github.com/recoil-labs/recoil-link) across virtual machines. A building block of [`@recoillink/sdk`](https://www.npmjs.com/package/@recoillink/sdk) and the CLI; most apps don't need it directly.

## Install

```bash
npm install @recoillink/deploy-sdk
```

## Status

Recoil Link is on **testnet** (Sepolia, Base Sepolia, OP Sepolia, BSC testnet), secured by one validator. Don't move real value with it yet.
