# @recoillink/cosmos-sdk

Recoil Link support for **Cosmos**: TypeScript bindings and helpers for the Cosmos SDK messaging module.

Used by [`@recoillink/sdk`](https://www.npmjs.com/package/@recoillink/sdk); most apps install the SDK rather than this package directly. Recoil Link is deployed on EVM testnets today: Cosmos support is in the codebase but not deployed yet.

## Status

Recoil Link is on **testnet** (Sepolia, Base Sepolia, OP Sepolia, BSC testnet), secured by one validator. Don't move real value with it yet.
