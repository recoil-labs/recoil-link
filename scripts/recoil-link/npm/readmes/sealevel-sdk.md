# @recoillink/sealevel-sdk

Recoil Link support for **Solana (SVM)**: a client for Recoil Link's Sealevel programs.

Used by [`@recoillink/sdk`](https://www.npmjs.com/package/@recoillink/sdk); most apps install the SDK rather than this package directly. Recoil Link is deployed on EVM testnets today: Solana (SVM) support is in the codebase but not deployed yet.

## Status

Recoil Link is on **testnet** (Sepolia, Base Sepolia, OP Sepolia, BSC testnet), secured by one validator. Don't move real value with it yet.
